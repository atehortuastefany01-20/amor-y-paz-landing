# Amor y Paz — Landing Page

Landing page interactiva para la tienda de ropa **Amor y Paz**.

## Funcionalidades

- Diseño responsive para escritorio, tableta y móvil.
- Catálogo de 18 productos con filtros por categoría.
- Carrusel de productos destacados.
- Fichas con tallas, colores, cantidades y detalles.
- Mensajes personalizados para consultar productos por WhatsApp.
- Menú móvil, navegación accesible y animaciones moderadas.
- Estados informativos para disponibilidad, envíos, pagos y cambios.

## Ejecutar el proyecto

No requiere instalación ni compilación. Abre `index.html` en un navegador o publícalo como sitio estático.

## Configurar WhatsApp

En `index.html`, reemplaza:

```js
const WHATSAPP_NUMBER = '';
```

por el número real con indicativo de país, sin `+`, espacios ni guiones.

Ejemplo para Colombia:

```js
const WHATSAPP_NUMBER = '573001234567';
```

## Información comercial

Antes de promocionar el sitio, confirma que los productos, precios, disponibilidad y condiciones comerciales correspondan a la información vigente de Amor y Paz.
